# 데이터 폴더

앱은 기본적으로 **프로젝트 루트의 `data`** 에서 CSV를 읽습니다.  
다른 경로를 쓰려면 환경 변수 `PODOMEDIA_DATA_ROOT` 를 설정하세요.

## 폴더 구조

```
data/
  기본정보/           ← 상권(베이스라인) CSV
    코엑스_성별.csv
    코엑스_연령.csv
    명동_성별.csv
    ...
  <세그먼트_폴더명>/  ← 세그먼트별 하위 폴더 (폴더명 = segmentId)
    전체_성별.csv
    전체_연령.csv
    코엑스_성별.csv
    ...
```

- `기본정보` 와 세그 폴더는 **반드시 `data` 바로 아래**에 두세요.
- 기존 `D:\2026\포도미디어` 에 있던 동일 구조를 이곳으로 복사하면 됩니다.
